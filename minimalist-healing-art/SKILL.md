# 极简治愈风景插画风格生成

用户收藏的小红书参考图（ohio_ooooo 治愈系插画 × Guim Tió Zarraluki 极简风景画）
背后是同一套视觉语言。本 skill 把该语言固化为可复用规则，任何主题输入都按此产出，
风格稳定统一。

## 触发与输入

- 用户给出任意主题（中文/英文皆可），例如"一个人的海边黄昏"、"雪原独行"、"草地家庭聚餐"。
- 可选附加要求：是否带文字、文字内容、希望偏哪个色系（暖灰 / 冷雾蓝 / 陶土橙 / 苔藓绿 / 雾紫 / 暗夜蓝）。

## 执行步骤

1. 先读 `references/style-guide.md`，把风格规范装入上下文。
2. 与用户确认主题（必要时）与两个选项：**要不要文字**、**主色调倾向**。
   用户没提就按规范默认执行：不带文字，色系从规范默认清单里挑最贴合主题的。
3. 按 style-guide 中的"提示词模板"组装生图提示词：主题 + 风格块 + 文字要求（如有）。
4. 调用图片生成工具：
   - **模型固定 gpt-image-2**（不要降级 nano-banana，人物质感差）
   - **比例固定 2:3 竖版**（gpt-image-2 不支持 3:4，2:3 为最接近竖版）
   - filename 用用户语言的主题短名；
   - 图片保存到 samples/ 下。
5. 生成后检查：留白是否足够、配色是否 5-7 种低饱和、是否有数码手绘笔触感（非水墨非水彩非平涂）、
   人物是否微缩且质感精致、氛围是否安静疏离、有无赛博感。
   若不达标 → 调整提示词重生成一次；仍不行 → 告知用户并给出当前最佳结果。

## 风格要点（速记版，完整规范见 style-guide.md）

- 留白 60%+：画面大部分为空旷背景，主体小而偏侧。
- 5-7 种低饱和颜色：色层丰富但不杂，无赛博感/荧光/霓虹。
- 数码手绘质感：Procreate 风格的数码画笔笔触，奶油哑光色调，朦胧温润——不是水墨、不是水彩晕染、不是平涂色块。
- 微缩人影：人物极小（5-10%），背影/侧影，无五官，手绘剪影非完美矢量。
- 安静疏离氛围：孤独但自洽，治愈而非悲伤。
- 2:3 竖版固定，gpt-image-2 模型固定。
- 禁止：摄影照片、3D渲染、矢量扁平、赛博/霓虹/荧光、写实油画、水墨/水彩晕染。

## 铁律

- **不复制原图**：不临摹 ohio_ooooo 或 Guim Tió Zarraluki 的任何具体画面/构图/角色。
- **不脱离体系**：不引入高饱和撞色、不做写实光影、不堆砌细节、不画大比例人物。
- **2:3 竖版 + gpt-image-2**：固定比例和模型，不可更改。
- 风格是默认值而非束缚：主题的"内容"由用户决定，风格永远服从本规范。

# 极简治愈风景插画风格生成

用户收藏的小红书参考图（ohio_ooooo 治愈系插画 × Guim Tió Zarraluki 极简风景画）
背后是同一套视觉语言。本 skill 把该语言固化为可复用规则，任何主题输入都按此产出，
风格稳定统一。

## 触发与输入

- 用户给出任意主题（中文/英文皆可），例如"一个人的海边黄昏"、"雪原独行"、"窗边的猫"。
- 可选附加要求：是否带文字、文字内容、希望偏哪个色系（暖灰 / 冷雾蓝 / 陶土橙 / 苔藓绿 / 雾紫）。

## 执行步骤

1. 先读 `references/style-guide.md`，把风格规范装入上下文。
2. 与用户确认主题（必要时）与两个选项：**要不要文字**、**主色调倾向**。
   用户没提就按规范默认执行：不带文字，色系从规范默认清单里挑最贴合主题的。
3. 按 style-guide 中的"提示词模板"组装生图提示词：主题 + 风格块 + 文字要求（如有）。
4. 调用图片生成工具：
   - 比例固定 **3:4（竖版）**，尺寸 1K 或 2K；
   - filename 用用户语言的主题短名；
   - 图片保存到 samples/ 下。
5. 生成后检查：留白是否足够、配色是否低饱和雾感、人物是否微缩、氛围是否安静疏离。
   若不达标 → 调整提示词重生成一次；仍不行 → 放弃文字只保留插画，并告知用户。

## 风格要点（速记版，完整规范见 style-guide.md）

- 极致留白：画面 70%+ 为空旷背景（天空/地面/水面/雾），主体只占 10-20%。
- 低饱和雾感色块：2-3 个大色块分割画面，色调灰雾柔和、高级克制，无高饱和原色。
- 平涂无光影：色块之间柔和过渡，无写实光影、无渐变、无体积感。
- 微缩人影：人物极小（画面高度的 5-10%），多为背影或侧影，无五官、无身份、无情绪。
- 自然/日常场景：旷野、湖泊、雪原、山野、海边、窗台、街角——宏大或微小的场景皆可。
- 安静疏离氛围：孤独但不悲伤，松弛但不空洞，"用最简单的画面安放最复杂的心事"。

## 铁律

- **不复制原图**：不临摹 ohio_ooooo 或 Guim Tió Zarraluki 的任何具体画面/构图/角色。
- **不脱离体系**：不引入高饱和撞色、不做写实光影、不堆砌细节、不画大比例人物。
- **3:4 竖版**：固定比例，不可更改。
- 风格是默认值而非束缚：主题的"内容"由用户决定，风格永远服从本规范。

# 极简治愈风景插画风格指南 (Style Guide)

> 本文件是 minimalist-healing-art skill 的完整视觉规范。
> 提炼自 ohio_ooooo（韩国治愈系插画）× Guim Tió Zarraluki（西班牙极简风景画）的共同视觉语言。

---

## 一、画面比例

固定 **3:4 竖版**。不可更改。

---

## 二、留白与构图

| 维度 | 规范 |
|------|------|
| 留白比例 | 画面 70%+ 为空旷背景（天空/地面/水面/雾气/纯色块） |
| 主体占比 | 10-20%，位置偏下或偏侧，四周大量透气 |
| 构图方式 | 大色块水平/斜向分割画面，形成天地/水岸/山野的极简结构 |
| 层级 | 最多 2-3 个色块层面；前景（人物/小元素）、中景（地平线/水面）、远景（天空/山影） |
| 人物位置 | 画面下方 1/4-1/3 处，极小，孤身一人，多为背影或侧影 |
| 边框 | 不加画框，画面边缘自然结束 |

### 构图铁律

- 画面必须有大面积"空"——天空、水面、雾气、纯色块都算空。
- 主体不可居中放大，必须偏小偏侧。
- 不堆砌元素：一张图最多 1 个人物 + 1-2 个环境元素（如一棵树、一盏灯、一块岩石）。

---

## 三、配色体系

### 底色

| 角色 | 色值 | 用途 |
|------|------|------|
| 暖雾白 | `#F0EDE8` | 天空/背景/大面积底色（暖调） |
| 冷雾白 | `#E8EAEC` | 天空/背景/大面积底色（冷调） |
| 浅灰 | `#D4D2CE` | 次级色块/过渡/地平线 |

### 主色系（每次只选 1 个主色系 + 1 个点缀色）

| 色系名称 | 主色 | 点缀色 | 气质 |
|------|------|------|------|
| 暖灰 | `#B5AFA8` | `#8A8278` | 安静、日常、温暖 |
| 冷雾蓝 | `#9BA8B5` | `#6B7B8D` | 清冷、清晨、冬天、海边 |
| 陶土橙 | `#C49B7A` | `#A07858` | 黄昏、秋天、温暖记忆 |
| 苔藓绿 | `#8B9B7E` | `#6A7A5E` | 自然、山野、春天 |
| 雾紫 | `#A89AB5` | `#83789A` | 黄昏、梦幻、疏离 |
| 暗夜蓝 | `#3A4555` | `#2A3340` | 夜晚、深邃、孤独 |

### 辅助色

| 角色 | 色值 | 用途 |
|------|------|------|
| 人物剪影色 | `#2B2B2B` 或主色系最深处 | 人物轮廓/背影 |
| 高光暗示 | 主色系提亮 15% | 色块边缘的微妙过渡 |

### 配色铁律

- **低饱和**：所有颜色饱和度 ≤ 25%，明度偏高或偏低，呈"雾化"质感。
- **少色**：一张图最多 3 个颜色（底色 + 主色 + 点缀），封顶 4 色。
- **无高饱和**：禁止纯红/纯蓝/纯绿/荧光色/撞色对比。
- **无渐变**：色块之间是平涂或极柔和的雾感过渡，不做 Photoshop 式渐变。
- **冷暖统一**：一张图要么全暖、要么全冷，不混搭冷暖。

## 四、质感与笔触

| 维度 | 规范 |
|------|------|
| 整体质感 | 雾感、柔焦、哑光——像隔了一层薄雾或磨砂玻璃 |
| 色块边缘 | 柔和过渡，不锐利，可有轻微的"晕染"感 |
| 笔触 | 平涂为主，可有极轻微的颗粒/噪点纹理（增加手作感） |
| 人物 | 纯剪影/色块，无五官、无细节、无衣纹——只是一个色块形状 |
| 光影 | 禁止。无光源方向、无阴影投射、无高光反射 |

### 禁止

- ❌ 写实渲染、3D 质感、油画笔触
- ❌ 精确透视、空间纵深（可暗示但不强调）
- ❌ 任何形式的光影（无太阳光斑、无投影、无反射）
- ❌ 复杂纹理（木纹/石纹/布纹等一律不做）

---

## 五、人物规范

| 维度 | 规范 |
|------|------|
| 大小 | 画面高度的 5-10%，极小 |
| 朝向 | 背影或侧影为主，极少正面 |
| 细节 | 无五官、无表情、无衣纹——纯色块剪影 |
| 姿态 | 站立、行走、坐着、远眺——安静的静态，无剧烈动作 |
| 数量 | 通常 1 人，最多 2 人（且两人之间有距离感） |
| 颜色 | 用画面中最深的颜色（炭黑或主色系暗部） |

### 人物铁律

- 人物是"存在于空间中的一个小点"，不是画面的主角——空间和留白才是主角。
- 人物没有身份、没有情绪、没有故事——ta 只是"一个人，在那里"。
- 禁止画大比例人物（超过画面 15%）、禁止画有表情的正面人物。

## 六、氛围

| 维度 | 规范 |
|------|------|
| 核心情绪 | 安静、疏离、孤独但自洽、松弛、治愈 |
| 叙事感 | "用最简单的画面，安放最复杂的心事" |
| 孤独定义 | 孤独不是悲伤，是成年人的独处与和解 |
| 力量感 | 画面给人"平静、松弛、与生活和解的力量" |

### 氛围关键词（提示词中使用）

```
quiet, solitary, peaceful, healing, contemplative, serene,
vast emptiness, gentle isolation, self-sufficient solitude,
calm and restrained, soft and muted, therapeutic stillness
```

## 八、生成后自检清单

- [ ] 留白是否 ≥ 70%？主体是否小而偏侧？
- [ ] 配色是否低饱和雾感？有没有跑出规定色板？
- [ ] 色块是否平涂？有没有出现不该有的光影/渐变？
- [ ] 人物是否微缩、无五官、背影/侧影？
- [ ] 氛围是否安静疏离？有没有变热闹/戏剧化？
- [ ] 比例是否 3:4 竖版？

任一项不过 → 调整提示词重生成一次；两次仍不行 → 放弃文字只保留插画，告知用户。
